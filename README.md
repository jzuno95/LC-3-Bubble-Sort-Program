# LC-3-Bubble-Sort-Program

## Project Description
This is a program using the Bubble Sort algorithm using LC-3 assembly language. 

The program:
* Reads 8 integers form user input
* Stores values in an array
* Sorts values using bubble sort
* Displays sorted output
* Uses subroutines
* Uses stack PUSH/POP operations
* Uses ASCII conversion
* Validates input values
* Rejects invalid characters
* Rejects values outside of 0 - 100

## Program Components
### Main Program
Controls:
* Input
* Sorting
* Output
  
### Subroutines
**READNUM**    
Reads and validates user input\
**PRINTNUM**   
Displays values to console\
**PUSH**   
Pushes values onto stack\
**POP**  
Pops values from stack  

## Example
**Input**  
9 2 10 50 34 89 72 22 \
**Output**  
2 9 10 22 34 50 72 89
